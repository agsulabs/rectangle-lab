# Rectangle Lab

## Beschreibung

Rectangle Lab ist ein kleines Python-Projekt zur Berechnung und Darstellung von Rechtecken. Der Benutzer gibt Länge und Breite ein, und das Programm berechnet die Fläche und den Umfang.

## Ziel des Projekts

Das Ziel des Projekts ist es, grundlegende Programmierkonzepte in Python praktisch zu lernen. Dazu gehören Benutzereingaben, Berechnungen, Funktionen, Klassen, grafische Darstellung und später die Speicherung von Daten.

## Geplante Funktionen

- Rechteck berechnen
- Fläche und Umfang anzeigen
- Rechteck später grafisch darstellen
- Rechteck später mit der Maus verändern
- Daten später speichern
- Benutzerregistrierung später hinzufügen
- später Verbindung zu einem Server/Backend herstellen
- Daten später über den Server in einer Datenbank speichern

## Technologien

- Python
- Git
- später: tkinter
- später: SQLite
- später: Server/Backend
